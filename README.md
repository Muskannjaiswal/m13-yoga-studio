🧘‍♀️ M13 Yoga Studio — Interactive Script & Web Experience

Welcome to the official repository for the M13 Yoga Studio interactive web experience!

At M13, we believe that finding your balance shouldn't start with a stressful, clunky website. This project was built to bring the calm, welcoming energy of our studio directly to your screen—helping new and returning students explore classes, understand our philosophy, and step onto the mat with confidence.

✨ What’s Inside?

We designed this interactive script to feel less like a standard webpage and more like a conversation with a friendly instructor at the front desk. Here is what it does:

Guided Class Discovery: Helps visitors find the right practice based on their mood, experience level, and energy—whether they need a slow, restorative Yin session or an energizing Vinyasa flow.

Interactive Flow & Prompts: Smooth, distraction-free transitions that keep the focus on breathing, mindfulness, and clear next steps.

Beginner-Friendly Onboarding: Demystifies studio etiquette, what to bring, and how to book a first session without overwhelming newcomers with jargon.

Responsive & Mindful Design: Built to look and feel serene across desktop, tablet, and mobile devices.

🚀 Getting Started

Want to run this locally or customize it for your own studio sessions? It takes less than a minute to get up and running.

Prerequisites

All you need is a modern web browser (Chrome, Safari, Firefox, or Edge). No heavy frameworks or complicated build tools required!

Quick Setup

Clone or download this repository to your local machine:

git clone https://github.com/your-username/m13-yoga-studio.git


Navigate into the project folder:

cd m13-yoga-studio


Launch the experience:
Simply double-click the main HTML file to open it in your browser, or use a local development server like VS Code's Live Server extension for real-time updates while you edit.

🛠️ Customizing the Experience

Want to tweak the script, update class schedules, or adjust the studio's welcome message?

Copy & Prompts: Head straight into the script sections to update instructor names, class descriptions, or seasonal workshop announcements.

Styling & Colors: Adjust the CSS variables at the top of the stylesheet to match your studio's seasonal palette (we love warm earth tones, soft sage, and off-white backgrounds).
